## 📌 О проекте

**Cloud File Storage** — это полнофункциональное веб-приложение для безопасного хранения, управления и обмена файлами. Проект построен на микросервисной архитектуре с использованием современных инструментов для обеспечения высокой производительности и масштабируемости.

### 🎯 Ключевые цели проекта:
- Предоставить пользователям надёжное облачное хранилище файлов.
- Обеспечить высокую скорость загрузки и скачивания файлов.
- Гарантировать безопасность данных и управление доступом.
- Быть готовым к горизонтальному масштабированию.

---

## ✨ Основные возможности

- **🔐 Безопасная аутентификация и управление сессиями**
    - Регистрация и вход в систему.
    - Сессии хранятся в Redis для быстрого доступа и масштабируемости.
- **📁 Полноценное управление файлами**
    - Загрузка, скачивание, удаление и переименование файлов.
    - Создание и управление папками.
    - Сортировка и фильтрация файлов.
- **🖼️ Предпросмотр файлов**
    - Поддержка предпросмотра изображений и документов (PDF, DOCX).
- **👥 Управление доступом**
    - Публичные и приватные файлы/папки.
    - Возможность делиться файлами по ссылке.
- **📊 Мониторинг и логирование**
    - Централизованное логирование для отладки.
    - Метрики для мониторинга производительности (Actuator).
- **🚀 Готовность к продакшену**
    - Полная контейнеризация (Docker + Docker Compose).
    - Готовность к развертыванию в облачных средах.

# Как развервнуть локально ?
- Клонируем репозиторий к себе на машину (git clone https://github.com/DmtritPlesko/cloud-file-storage.git)
- переходим в директорию (cd cloud-file-storage)
- создаём файл .env (nano .env) (ниже пример того что должно в нём быть)
### Пример .env
```
# PostgreSQL
POSTGRES_USER=
POSTGRES_PASSWORD=
POSTGRES_DB=
DB_PORT=

# Redis
REDIS_PORT=

# MinIO
MINIO_PORT=
MINIO_CONSOLE_PORT=
MINIO_ACCESS_KEY=
MINIO_SECRET_KEY=

# Spring Boot
SPRING_DATASOURCE_URL=
SPRING_DATASOURCE_USERNAME=
SPRING_DATASOURCE_PASSWORD=
SPRING_DATA_REDIS_HOST=
SPRING_DATA_REDIS_PORT=
MINIO_URL=http://minio:
MINIO_BUCKET=
MINIO_DELETE_BATCH_SIZE=
```

- из директории запускаем сразу же docker compose (docker-compose up -d)
- Доступ будет через проброшенные порты в докере (по базе 8080 и хост http://localhost)
 
- (на хосте при установке JRE следить за версиями javac и maven) в pox.xml и компонетах должны быть одинаоквые
